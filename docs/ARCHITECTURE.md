# Architecture
Modular Laravel monolith: Laravel 13/PHP 8.3+, Livewire 4, Blade, Tailwind 4, Flux free, Alpine, PostgreSQL, Redis, Reverb/Echo, Fortify, Spatie Permission, Pest, Pint, Larastan, Docker Compose and GitHub Actions. Verify dependency compatibility during scaffold. No automatic deployment.
Presentation: app/Livewire and resources/views; domain actions in app/Actions/{Patients,Appointments,Visits,Queues,Clinical}; models, enums, policies, events, jobs and services in standard Laravel directories. PostgreSQL authoritative; Redis for cache/jobs; Reverb broadcasts only committed state. Use transactional actions and policy checks at every entry point. Store UTC timestamps and derive operational dates from configured clinic timezone. Separate sanitized display read model. Tests in tests/Feature and tests/Unit.

# Operational workflow
Reception searches or registers patient, verifies appointment or walk-in, checks in and creates one visit. If triage is required or selected for optional service, issue triage ticket and route to requested service after assessment; otherwise issue requested service ticket. Staff call, recall, skip/requeue or start service, record authorized clinical notes, complete or transfer. Transfer closes current ticket and creates next ticket atomically within same visit. Complete visit only when all required services resolved; skipped/cancelled tickets require explicit disposition. Appointment completion follows visit completion.
Appointment states: scheduled, confirmed, checked_in, completed, cancelled, no_show. Rescheduling audited; no active ticket before check-in. Visit states: checked_in, in_progress, completed, cancelled, left_without_service. Queue states: waiting, called, serving, skipped, completed, transferred, cancelled. See QUEUE_ENGINE.md. Example T-012 → C-018 → L-007 → C-025 → P-009 under one visit.

# Project scope

Single clinic, walk-in and receptionist-booked appointments, receptionist-only registration, optional triage, daily per-service tickets, visual and voice announcements, demographics and clinical notes. Laravel Livewire and Blade modular monolith.

See [Requirements](REQUIREMENTS.md) for authoritative scope and exclusions, [Architecture](ARCHITECTURE.md) for design, and [Implementation plan](IMPLEMENTATION_PLAN.md) for eight pending phases. No production use until privacy and clinical policies are approved.
